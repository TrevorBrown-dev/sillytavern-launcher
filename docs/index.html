SillyTavern Launcher

Installs SillyTavern on your Windows PC in one click and lets you use it from your phone. No terminal, no admin account.

Looks like you're not on a Windows PC. Open this page on the PC you want SillyTavern on, then use your phone with it afterwards.

Then

  1. Open the downloaded file. Windows will say "Windows protected your PC" because the file isn't signed. Click More info, then Run anyway.
  2. Click Install. Leave both boxes ticked. It downloads what it needs (a few minutes). Windows asks once to allow it through the firewall; click Yes.
  3. That's it. SillyTavern opens in your browser. Next time, use the SillyTavern shortcut on your desktop. For your phone, scan the QR code the launcher shows while on the same Wi-Fi.

Questions

Is the "Windows protected your PC" warning a problem?

No. It appears for any program that isn't signed with a paid certificate. The source code is public on GitHub if you want to check it.

Where does it install, and how do I remove it?

Everything goes into %LOCALAPPDATA%\SillyTavern and nothing else on the PC is touched. To uninstall, quit the launcher from the tray icon, delete that folder and the desktop shortcut.

Where are my chats and characters?

In %LOCALAPPDATA%\SillyTavern\SillyTavern\data. Updates from the launcher keep that folder.

My phone can't open it

The PC has to be on, the launcher running, and both devices on the same Wi-Fi (not mobile data, not a guest network). The launcher's "It doesn't load on my phone" section has the rest.

Something isn't working

In the launcher, click Save logs to Desktop. It's in the Maintenance section, on any error screen, and in the menu when you right-click the tray icon by the clock. It puts a zip on your Desktop; send that file to whoever is helping you. It never contains your chats or passwords. If the launcher won't open at all, press Win+R, paste %LOCALAPPDATA%\SillyTavern\logs and send the newest files from that folder.

The launcher window is blank

On Windows 10, install the WebView2 runtime from Microsoft and open the launcher again. Windows 11 already includes it.
